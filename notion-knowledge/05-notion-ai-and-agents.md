# 05 — Notion AI, Agents & Custom Agents

## 1. Evolution
- 2023: Notion AI (writing assistant: `/ai`, space, Q&A over workspace).
- 2024: Q&A, AI connectors (Slack, Google Drive), AI Autofill properties.
- May 2025: Notion AI for Work — AI Meeting Notes, Enterprise Search, Research Mode, model choice.
- **Sep 18, 2025 — Notion 3.0**: **Notion Agent** (autonomous, multi-step, up to ~20 min runs touching hundreds of pages; personalization page as memory), row-level DB permissions, MCP connectors.
- Late 2025/2026: **Custom Agents** (scheduled/triggered team agents), Skills, AI Autofill via agents, Plan Mode, sub-agents, External Agents (Claude, Cursor), Notion Agents iOS app, Developer Platform & Workers.

## 2. Where AI appears (entry points)
- Sidebar **Notion AI** (chat, full page).
- Floating AI button bottom-right / top-bar **AI icon** → side panel with current page as context.
- `Space` on empty line or `/ai` in editor.
- Select text → **Ask AI / Edit with AI**.
- Search → **Ask AI** (Enterprise Search).
- Database: AI Autofill properties, "build views/formulas with AI", AI formula writer.
- AI Meeting Notes block / Meetings sidebar.
- Comments: `@Notion AI` or `@agent-name`.
- Notion Calendar/Mail AI features.
- Mobile: AI Notes, Agent chat, iOS Notion Agents app.

## 3. Notion Agent (personal agent) — chat UI controls
- **Prompt box** with: `@` add context (pages, people, databases, connected apps, files), **attach** (files, images — PDFs/DOCX/XLSX/PPTX readable since Jul 2026), **mic** (dictation), **Model picker** (Auto + Claude Opus/Sonnet/Haiku, GPT-5.x, Gemini 3, Grok, Kimi, GLM, MiniMax…; scorecards speed/intelligence/cost, pin favorites, **effort** slider — Aug 2026), **Sources toggle** (Workspace / Web / connected apps / "Notion only"), **Research mode** (deep research reports with citations), **Plan mode** (asks clarifying questions & builds plan before bulk changes — May 2026), `/` **Skills** picker.
- Chat header: New chat, Chat history (search past chats), **Share chat as read-only link** (Apr 2026; manage in Settings → Public pages → Shared AI chats), open as full page / side panel, `•••` (rename, delete chat).
- **Personalization / Instructions page**: a Notion page the agent reads as memory ("how I like updates formatted", triage rules). Edit anytime.
- Capabilities: create/edit pages & databases (build entire DB systems), bulk-update rows, search workspace + web + connectors, summarize, draft docs, schedule meetings (Calendar; Apr 2026), draft/send email (Mail/Gmail/Outlook), create Word/Excel/PowerPoint-style files, build interactive HTML blocks, generate images, edit in place, suggest edits, undo all agent changes ("Undo" / view changes list).
- Each response shows **steps** taken (searched X, edited Y pages) with links and a **Revert/Undo** option.

## 4. Custom Agents (team agents)
- Create from **Library → Agents → New agent** (or sidebar Agents, or chat "build me an agent").
- Configuration tabs:
  - **Instructions** (what it does; written in natural language; can be generated by AI).
  - **Triggers**: Schedule (daily/weekly/cron-like), Database events (page added, property changed), Slack message/mention in channel, Email received, **Meeting note summarized** (Jul 2026), Webhook (via Workers), Manual (@mention, button, automation "Run agent").
  - **Tools & access**: which pages/databases it can read/edit (share via Share menu too), connectors (Slack incl. private channels, Mail, Calendar, Google Drive, GitHub, Jira, Linear, Salesforce, Box, Teams, n8n, Mercury, Mixpanel, Miro, ClickHouse, custom MCP), web access, **Workers** (custom code tools).
  - **Model** (admin can restrict allowed models & set default — Sep 2026).
  - **Sub-agents** (3.7): delegate to other Custom Agents.
  - **Credit limit** per agent.
  - **Activity / Runs log** (what ran, what changed, who triggered), test run, pause/disable.
  - Sharing: who can use/edit the agent; **Duplicate agent**.
- Embed an agent in a doc (3.7). @-mention agents in pages/comments/Slack.
- **Agent Directory / "Hall of fame"** examples (Ramp, Clay, Vercel) with setup checklists.
- Billing: **Notion credits** — Custom Agents free to try until May 3, 2026; since May 4, 2026 run on purchasable credits ($10 per 1,000 credits/month). Cheaper models use up to 10× fewer credits.
- Admin guardrails (May 2026): who can create agents (users/groups), per-agent & workspace credit limits, credits dashboard (usage by agent, trends), instant disable, auto-pause on runaway spend, limit-increase requests, audit log (Enterprise).

## 5. Skills (Mar–Sep 2026)
- Reusable named instructions ("Write MBR", "Review PRD like my manager"). Create by chatting with Agent or from suggestions.
- Run via `/` in Agent chat; can run automatically.
- **Skills library** database shared across workspace (versioned).
- **Export as `SKILL.md`** for Claude Code, Codex, Cursor, Gemini, Grok (3.7).

## 6. AI Autofill (database)
- AI properties: Summary, Key info, Keywords/tags, Translation, Custom prompt. Auto-update on edit toggle; "Update all pages" button. Since Apr 2026 powered by Custom Agents for continuous enrichment/categorization (rolling out); basic autofill included in Business/Enterprise.

## 7. AI Meeting Notes
- Start: `/meet`, Meetings sidebar, Notion Calendar event "Start transcribing", mobile one-tap (works in background/locked).
- UI: **Start/Pause/Stop transcribing**, language selector, audio source (mic/system audio on desktop), consent notice; tabs **Summary / Notes / Transcript**; speaker labels (Jul 2026); custom summary instructions/templates; action items; upload audio files for transcription (Jul 2026).
- Output: summary, action items (can push to Tasks DB), follow-up email drafts; triggers Custom Agents when summarized.
- Available via API and MCP.

## 8. Enterprise Search
- AI search across Notion + connected apps (Slack, Google Drive, GitHub, Jira, Linear, Microsoft Teams, SharePoint/OneDrive, Gmail, Box, Salesforce, Asana (Feb 2026), etc.), respects source permissions. Returns answer with citations. Business/Enterprise; AI Search 50% faster (3.7).

## 9. Research mode
- Deep multi-step research: plans, searches workspace + web, writes report page with citations.

## 10. AI connectors & MCP
- Settings → **Connections** (unified tab, May 2026): personal & workspace connections, AI connectors, MCP servers, API tokens.
- Custom MCP connections (beta, Business/Enterprise; 3.7): GitHub, Amplitude, etc. — changes in connected tools require approval.
- Notion's own **MCP server** lets external AI (Claude, ChatGPT, Cursor) read/write Notion.

## 11. External Agents (Jul 2026)
- Bring Claude, Cursor (and via API Codex, Decagon) into Notion: assign tasks on a shared board, @-mention them, watch runs. External Agents API (alpha).

## 12. Models (as of Sep 2026)
- Picker includes Auto plus models such as Claude Opus 5 / 4.x, Sonnet, Haiku 4.5; GPT-5.6 Sol, GPT-5.4 / Mini / Nano; Gemini 3; Grok 4.3; Kimi K3; GLM 5.2 (open-weight); MiniMax M2.5. "Notion Knowledge Board" benchmarks models on everyday work.
- Admin model controls: Settings → Notion AI → General → Model controls.

## 13. Privacy
- AI data not used to train models; LLM provider retention 30 days, **zero data retention** on Enterprise. Admins can disable AI features, web search, connectors.

## 14. Plans
- Free/Plus: limited trial of Notion Agent, meeting notes, Enterprise Search.
- Business/Enterprise: full Notion AI included; Custom Agents & Workers consume Notion credits.
