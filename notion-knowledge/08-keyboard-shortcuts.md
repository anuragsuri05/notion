# 08 — Keyboard Shortcuts (official list + extras)

`Cmd` = Mac, `Ctrl` = Windows/Linux. Press `?` (or search "Keyboard shortcuts") in the app for the in-app list.

## Most popular
| Action | Mac | Windows |
|---|---|---|
| Search in page | Cmd+F | Ctrl+F |
| Search / jump to page | Cmd+P or Cmd+K | Ctrl+P or Ctrl+K |
| Copy page URL | Cmd+L | Ctrl+L |
| Back / Forward | Cmd+[ / Cmd+] | Ctrl+[ / Ctrl+] |
| Prev / next DB page in peek | Ctrl+Shift+K / J | Ctrl+K / J |
| Toggle dark mode | Cmd+Shift+L | Ctrl+Shift+L |
| Toggle sidebar | Cmd+\ | Ctrl+\ |
| Open Notion AI | Cmd+J | Ctrl+J |
| Go up one level | Cmd+Shift+U | Ctrl+Shift+U |
| Zoom in/out | Cmd + / − | Ctrl + / − |

## Markdown autoformat
- Inline: `**bold**`, `*italic*`, `` `code` ``, `~strike~`, `$$equation$$`
- Line start: `-`/`*`/`+` bullet · `[]` to-do · `1.`/`a.`/`i.` numbered · `#`/`##`/`###`/`####` headings · `>` toggle · `"` quote · `---` divider · ` ``` ` code block

## Triggers
- `/` slash menu · `@` mentions/dates/reminders (`@remind`) · `[[` link or create page · `+` link/create page · `:` emoji · `Space` on empty line = AI

## Notion Calendar (selected)
`T` today · `J/K` next/prev period · `D`/`W`/`M` day/week/month · `C` create event · `Cmd+K` command menu · `Cmd+J` join next meeting · `Z` time zones · `Shift+Cmd+?` shortcuts.
